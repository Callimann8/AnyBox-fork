# d3d12_x technical debt

Serves `d3d12_x.dll` and `d3d12_xs.dll` (D3D12.X).

### Functional

- [Inventory](../../../core/libs/xdll/d3d12_x/Inventory.cpp) (d3d12_x) - every entry point stops the title. D3D12.X interfaces have console-specific methods and layouts, so they cannot be forwarded to desktop `d3d12.dll`; a translation layer to desktop D3D12 or Vulkan is needed, along with a shader path for console-compiled shaders
  Closes when: a title draws its first frame
